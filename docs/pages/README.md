# Pages Documentation

This section describes each main page in the application, its purpose, and key features.

---

## Main Page (`/`)
- **File:** app/page.tsx
- **Purpose:** Landing page for all users.
- **Features:** Welcome message, navigation, call-to-action.

## Dashboard (`/dashboard`)
- **File:** app/dashboard/page.tsx
- **Purpose:** User dashboard after login.
- **Features:** Project overview, user stats, quick actions.

## Login (`/auth/login`)
- **File:** app/auth/login/page.tsx
- **Purpose:** User authentication.
- **Features:** Login form, error handling, redirect on success.

## Register (`/auth/register`)
- **File:** app/auth/register/page.tsx
- **Purpose:** New user registration.
- **Features:** Registration form, validation, success message.
